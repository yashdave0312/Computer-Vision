# Computer Vision Learning & Projects

This repository contains my journey of learning **Computer Vision**, starting from the fundamentals and gradually moving toward real-world Computer Vision projects.

The goal of this repository is to understand how computers can process, analyze, and extract useful information from images and videos using Python and Computer Vision libraries.

## 🚀 What is Computer Vision?

Computer Vision is a field of Artificial Intelligence that enables computers to **understand and interpret images and videos**.

It is used in applications such as:

* Face Detection
* Object Detection
* Image Classification
* Image Segmentation
* Facial Recognition
* OCR
* Pose Estimation
* Autonomous Vehicles
* Medical Image Analysis
* Video Processing
